# test-streamlit

A sample [Streamlit](https://streamlit.io/) application.

## Getting started

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the app:

   ```bash
   streamlit run app.py
   ```

The app will open in your browser at `http://localhost:8501`.

## Features

- Interactive sidebar with configurable data points and chart type
- Sample data table
- Line, bar, and area charts
- User input with a greeting
- Summary statistics on demand
